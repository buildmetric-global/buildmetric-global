# BuildMetric — Starter Website

This is the first static MVP website for BuildMetric. It is built with plain HTML, CSS and JavaScript, so it does not require a framework or paid software.

## What's included
- Responsive homepage and mobile navigation
- Service overview for BOQ preparation, cost estimation and QS consultancy
- Interactive area × user-entered rate cost estimator
- Enquiry form that can prepare an email (requires your real email address)
- Basic page title and description for search engines

## Run it on your computer
1. Download and unzip the project.
2. Open the `index.html` file in Chrome, Edge or Firefox.
3. Edit the text and styles in a code editor such as Visual Studio Code.

## Important setup before publishing
1. Open `script.js`.
2. Find `const BUSINESS_EMAIL = "globalbuildmetric@gmail.com";`
3. Replace it with an email address you control, for example `yourname@gmail.com`.
4. Save and test the enquiry form.

## Publish free with GitHub Pages
1. Create a GitHub account at https://github.com/.
2. Create a new public repository named `buildmetric`.
3. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will provide a public website address after deployment.

Cloudflare Pages is another free static-hosting option. A custom domain usually costs money and can be added later.

## Important business and professional notes
- The calculator is a simple illustrative tool. It does not contain verified market rates, country-specific cost databases, tax rules, or a complete construction cost model.
- Do not present calculator output as a tender price or professional cost plan.
- Before offering regulated or reserved professional services, check the applicable professional registration, licensing, insurance and practice requirements in each country.
- The enquiry form currently uses the visitor's email app (`mailto:`). It is not a secure database or an online form service. A backend or form provider is needed for reliable lead capture.
- The brand name is a working choice. Check company-name, trademark and domain availability before investing in branding or registering it.
